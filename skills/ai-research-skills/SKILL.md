# ai-research-skills

This is a project-scoped entry point for the pinned upstream collection.

1. Search `references/catalog.md` for the requested topic or workflow. It indexes 17 source skills. Read only the matching entries.
2. Open the selected linked `SKILL.md`, resolving its path relative to the catalog file, and follow its instructions. Keep scripts, references, and assets in their original source directory.
3. Check that the tools, network access, or accounts needed by that selected skill are available before claiming the operation works.
4. Source code is installed locally; optional external accounts and services are not provisioned by installing these instructions. Do not execute installers for unrelated packs.

From the repository root, upstream README and license are under `.local/skill-sources/ai-research-skills/`. Exact source revisions are recorded in the project-root `skills.lock.json`.

## Canonical sources

The 17 catalog skills are installed from their five canonical repositories under `.local/skill-sources/` in the repository root; the catalog repository alone contains no SKILL.md files.
Instruction-only workflows can be used directly. Zotero, NotebookLM, research-hub automation, and optional model delegation need their own runtime and authorization; these are not activated merely by installing the instructions.
